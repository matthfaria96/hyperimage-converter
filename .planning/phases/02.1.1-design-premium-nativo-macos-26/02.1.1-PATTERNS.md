- MainView ALREADY uses `NavigationSplitView(columnVisibility:)` with the browser as sidebar (default `.detailOnly`). D-01 `.inspector` must be validated at 1080x640 with `scripts/ui-smoke.sh` (narrow shots) before committing. Fallback: keep trailing column.

No `glassEffect`, `GlassEffectContainer`, `.inspector`, `scrollEdgeEffectStyle`, `sensoryFeedback`, `matchedGeometryEffect`, or `contentTransition(.numericText())` anywhere (grep-verified).
- Tests (`Tests/HyperImageAppTests/AppFlowTests.swift`, `@testable import HyperImage`) do NOT instantiate any View. They use: `AppModel` (`add`, `clear`, `move(_:toFolder:)`, `applyRename`, `undoLastRename`, `lastRename`, `setSort`, `isScanning`, `totalBytes`, `hasFolderItems`, `alert`, `restore`), `ConversionRunner()` (+ `record(for:)`, start), `ConvertSettings`, `AdvancedStep.applying(_:to:)`, `BatchRename`, and `SheetRoute.advanced(.crop).id == "advanced-crop"` / `SheetRoute.advanced(nil).id == "advanced"` (lines 332-333). Stable signatures: `SheetRoute` cases and `id` strings, `AppModel`/`ConversionRunner`/`ConvertSettings`/`AdvancedStep` API, `DebugLaunch.apply(to:) -> SheetRoute?`. View structs may be freely changed.

## Pattern Assignments

### State access (all views)
Source: MainView.swift:21-27, SettingsPanel.swift:5-12
```swift
@Environment(AppModel.self) private var app     // @Observable model, injected once
let runner: ConversionRunner                     // passed down; owned by MainView @State
var body: some View {
    @Bindable var app = app
    let settings = $app.state.convert           // Binding<ConvertSettings>
```
Sub-sections take `@Binding var settings: ConvertSettings` (AdvancedStepsCard.swift:6) or `$app.state.rename`. Keep this; for D-04 selection use `List(selection: $app.selection)` (`app.selection` is `Set<URL>`; set in DebugLaunch via `app.selection = [first.url]`).

### Sheets (SheetRoute) - MainView.swift:4-16, 81-89
```swift

case .formatSettings: FormatSettingsSheet()
case let .advanced(step): AdvancedOptionsSheet(initialStep: step)
case let .conversionPreview(url): ConversionPreviewSheet(initial: url)
case .errors: ErrorListSheet(failures: runner.failures)

```
Open from anywhere: `app.route = .advanced(step)`. Do not rename cases or ids. Sheets use `@Environment(\.dismiss)`; RenamePreviewSheet.swift:7-50 is the current VStack + manual HStack buttons pattern (`Button("Fechar", role: .cancel).keyboardShortcut(.cancelAction)`, `.borderedProminent` + `.defaultAction`). D-08 moves these into `.toolbar { ToolbarItem(placement: .cancellationAction/.confirmationAction) }`. Preserve the `.task { Task.detached ... withTaskCancellationHandler }` plan computation (lines 42-49) untouched. The Table currently has no height rule (P-11): drop `minHeight: 480`, size by `entries.count` (min 4 rows).

### Animation + Reduce Motion pattern to extend (DropZoneViews.swift:100-130)
```swift
@Environment(\.accessibilityReduceMotion) private var reduceMotion
TimelineView(.animation(paused: !targeted || reduceMotion)) { ... }
.symbolEffect(.bounce, value: targeted)
.contentTransition(.symbolEffect(.replace))
```
Create one shared helper (e.g. `Shared/Motion.swift`: a ViewModifier/func returning `reduceMotion ? .easeInOut(0.15) : .snappy`) and use it everywhere (D-10).

### Debug hooks - DebugLaunch.swift (whole `#if DEBUG` enum)
`env` dict; keys: HYPERIMAGE_FILES, SHEET (advanced|format|preview|progress|rename), STEP, OPTIONS, WINDOW=about, VFOLDER, MODE, DROP, SELECT, WINDOW_SIZE, OUT, SNAPSHOT (dir), SNAPSHOT_DELAY. `scheduleSnapshot()` after delay draws every visible window via `bitmapImageRepForCachingDisplay` to `"\(index)-\(title).png"` then `exit(0)`. Call sites: MainView.onAppear `#if DEBUG` (lines 71-77). Add `HYPERIMAGE_APPEARANCE=light|dark` in `apply(to:)` as `NSApp.appearance = NSAppearance(named: .aqua/.darkAqua)`, and a `HYPERIMAGE_INSPECTOR=0|1` if needed. Note: window.title is the snapshot filename, so changing navigationTitle to the mode name changes PNG names (smoke only counts files).

### Smoke script - scripts/ui-smoke.sh
`shot NAME ENV=...` function runs `.build/debug/HyperImage`, `sleep ${WAIT:-7}`, counts PNGs against `EXPECT` (1 = main window, 2 = main + sheet/window). Add loops over `HYPERIMAGE_APPEARANCE in light dark` and `HYPERIMAGE_WINDOW_SIZE=1080x640` for all sheets/modes (existing narrow loop: convert compress rename; add upscale). Use `NAME-light/-dark` suffix.

### Localization (D-12) - Resources/Localizable.xcstrings
sourceLanguage `pt-BR`; key = the Portuguese literal itself; only `en` localization added:
```json
"Modo" : {
  "localizations" : {
    "en" : { "stringUnit" : { "state" : "translated", "value" : "Mode" } }
  }
},
```
Entries are sorted alphabetically (JSON, 2-space, ` : ` separator). Interpolations use `%@` / `%lld` (e.g. `" · %lld com erro"`). Views use `Text("literal")`/`LocalizedStringKey`; non-View strings use `String(localized:)` (MainView.swift:98,105). New strings (e.g. "Mostrar no Finder", "Alterar…" already exists?) must be added with en values; edit via a script (python json round-trip, preserving key order) rather than by hand.
